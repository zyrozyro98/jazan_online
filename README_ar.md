# نظام أتمتة طلاب جيزان

نظام Windows لتجهيز الطلاب تلقائياً بحسب التخصص والشعبة، مع إمكانية تحديد رابط المحاضرة وتعبئة بيانات كل طالب تلقائياً عبر المتصفح.

## المميزات

- إدارة شُعب و تخصصات مستقلة
- قاعدة بيانات محلية SQLite
- واجهة مستخدم متقدمة باستخدام Tkinter/ttk
- أتمتة تسجيل الدخول وتعبئة بيانات الطالب والنقرات المنزلية
- إدارة أوامر الأتمتة بسهولة ومرونة
- تشغيل لأكثر من طالب بنفس الوقت عبر مؤشرات متعددة
- إعدادات Render جاهزة للتكامل عند الحاجة

## المتطلبات

- Python 3.10+
- متصفح Chrome أو Edge
- اتصال إنترنت

## تثبيت

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## التشغيل

```bash
python -m app.main
```

## هيكل المشروع

- app/main.py : نقطة الدخول
- app/db.py : إدارة قاعدة البيانات المحلية
- app/automation.py : منطق الأتمتة عبر Selenium
- app/ui.py : واجهة المستخدم
- app/render_manager.py : إعدادات Render

## كيفية الاستخدام

1. افتح التطبيق
2. أضف التخصصات والشُعب
3. أضف الطلاب مع رقمهم الجامعي/الهوية
4. أضف أوامر الأتمتة مثل:
   - فتح الرابط
   - تعبئة اسم الطالب
   - تعبئة الرقم الجامعي
   - الضغط على زر الدخول
5. اختر الشعبة والتخصص
6. الصق رابط المحاضرة
7. اضغط تشغيل الأتمتة

## إدارة الأوامر

يتم إدارة الأوامر من خلال قائمة الأوامر، حيث يمكنك تحديد:

- نوع الأمر: فتح الرابط، تعبئة نص، ضغط زر، انتظار
- نوع المحدد: css, xpath, id, name, class
- قيمة المحدد
- نص القيمة المراد إدخاله
- ترتيب التنفيذ

## متغيرات القيم

يمكن استخدام القيم التالية داخل `value_template`:

- `{full_name}`
- `{university_id}`
- `{national_id}`
- `{program_name}`
- `{section_name}`

## ملاحظات مهمة

- يتطلب النظام معرفةSelectors الصحيحة لموقع المحاضرة الحقيقي.
- لاستخدام Chrome تلقائياً، تأكد من تثبيت Chrome أو Edge بشكل صحيح.
- إذا كنت تريد ربط التطبيق مع Render، استخدم ملف `app/render_manager.py` كقاعدة للتكامل.

## مثال سريع لأمر تعبئة

- نوع الأمر: fill
- نوع المحدد: id
- قيمة المحدد: `studentName`
- قيمة الإدخال: `{full_name}`

## مثال سريع لأمر الضغط

- نوع الأمر: click
- نوع المحدد: css
- قيمة المحدد: `button[type="submit"]`

## ملاحظة عن Render

هذا المشروع يتضمن دعمًا تجريبيًا لربط render من خلال واجهة نمطية قابلة للتوسعة، لكن إعدادات Render الفعلية تعتمد على حسابك وأذوناتك. يمكنك توسيع `render_manager.py` لتتوافق مع API الخاص بك.
